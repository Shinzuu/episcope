The pipeline runs end to end and passes 141 automated tests. The hidden-drop drill passed from a clean clone
on 11 Oct at SF=0.05: a new 14-day drop added 8,292 rows, a re-run added no duplicates, and the dashboard data
was 9.64\,MB with no counts from 1 to 4. What is missing is mostly evidence and writing: the scaling study,
the Spark optimisation measurements, the detection and backtest result files, the usability test, the report
and the video. All 14 commits so far are Shezan's and fall on one day; R9 grades each person's own Git share,
so \textbf{everyone must commit their own work from now on}.

The deadline has not been announced. Plan as if it is a few days away.

\section*{Rules for everyone}
\begin{itemize}
\item Commit your own work under your own Git identity, in small commits that start with the requirement ID,
for example \texttt{AN-8: ...}. Nobody commits in someone else's name.
\item Never commit \texttt{.env}, a salt or a key. Data stays out of Git (\nolinkurl{data/} and \nolinkurl{lake/} are ignored).
\item Every number in the report and the video comes from a file in \nolinkurl{docs/experiments/} of the final run.
\item Nobody tags \texttt{v1.0} or records the video until the group agrees the code is frozen.
\item Write your own half-page reflection (Appendix C) and agree the contribution matrix (Appendix B) together.
\end{itemize}
